📘 BUKU PANDUAN SPLDV

1. Apa itu SPLDV?

Sistem Persamaan Linear Dua Variabel (SPLDV) adalah dua persamaan matematika yang masing-masing memiliki dua variabel (huruf yang belum diketahui nilainya, biasanya x dan y).

Tujuan kita adalah mencari pasangan nilai (x, y) yang benar untuk kedua persamaan sekaligus.

2. Cara Menerjemahkan Cerita

Misalkan: "3 mangkok bakso dan 2 es teh harganya Rp 45.000".

  • Misalkan harga 1 mangkok bakso = x
  • Misalkan harga 1 es teh = y

Maka persamaannya menjadi: 3x + 2y = 45000

📈 Metode Grafik

Mencari solusi dengan cara menggambar kedua garis pada koordinat Kartesius. Titik potong (pertemuan) kedua garis tersebut adalah solusinya.

🔄 Metode Substitusi

Menyatakan salah satu variabel dalam bentuk variabel lain, lalu memasukkannya (menggantinya) ke persamaan yang satu lagi.

➕ Metode Eliminasi

Menghilangkan salah satu variabel dengan cara menjumlahkan atau mengurangkan kedua persamaan, sehingga tersisa satu variabel untuk dihitung.

3. Contoh Soal & Pembahasan

Misalkan kita memiliki soal persamaan: x + y = 5 dan x - y = 1. Mari kita buktikan bahwa ketiga metode akan menghasilkan jawaban yang sama!

📈 Penyelesaian Metode Grafik

  • Cari titik untuk x + y = 5: Jika x = 0 maka y = 5 (0,5). Jika y = 0 maka x = 5 (5,0). Tarik garis.
  • Cari titik untuk x - y = 1: Jika x = 0 maka y = -1 (0,-1). Jika y = 0 maka x = 1 (1,0). Tarik garis.
  • Perhatikan grafik! Kedua garis tersebut akan menyilang dan bertemu tepat di titik (3, 2).
  • Jadi, solusinya adalah x = 3, y = 2.

🔄 Penyelesaian Metode Substitusi

  • Ubah persamaan kedua menjadi bentuk x:
    x - y = 1  →  x = y + 1
  • Substitusikan (masukkan) nilai x tersebut ke persamaan pertama:
    (y + 1) + y = 5
  • Selesaikan persamaannya:
    2y + 1 = 5  →  2y = 4  →  y = 2
  • Masukkan nilai y = 2 ke persamaan awal (x = y + 1) untuk mencari x:
    x = 2 + 1  →  x = 3
  • Jadi, solusinya adalah x = 3, y = 2.

➕ Penyelesaian Metode Eliminasi

  • Susun kedua persamaan ke bawah rata sejajar:
    • x + y = 5
    x - y = 1
    --------- (+)
  • Untuk mengeliminasi (menghilangkan) y, kita jumlahkan (+) kedua persamaan karena tandanya berlawanan (+y dan -y):
    • (x + x) + (y - y) = 5 + 1
    2x = 6  →  x = 3
  • Sekarang substitusikan (masukkan) x = 3 ke persamaan awal (misal x + y = 5) untuk mencari y:
    3 + y = 5  →  y = 2
  • Jadi, solusinya adalah x = 3, y = 2.
